# API Design Skill
1. Read requirements.
2. Read ERD.
3. Read API specification.
4. Map route to resource and requirement.
5. Implement validation.
6. Implement envelopes.
7. Implement pagination/filtering/sorting.
8. Run validation matrix.
9. Record evidence.

Review: every list paginates; default 20; max 100; unknown sort rejected; errors have correct status; envelopes are consistent; rate limit is configuration-driven.
