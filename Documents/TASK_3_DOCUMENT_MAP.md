# Task 3 Document Map

## Core documents
1. `PRD.md` / requirements: product purpose, users, five important actions.
2. `DATA_MODEL_ERD_SPECIFICATION.md`: entities, fields, relationships, cardinality, hard database decisions, ERD.
3. `API_DESIGN_SPECIFICATION.md`: resources, endpoints, pagination, filtering, sorting, envelopes, validation and rate limiting.
4. `VALIDATION_AND_ERROR_MATRIX.md`: testable bad-input and error behaviour.
5. `README_API_DOCUMENTATION.md`: endpoint documentation with curl examples.
6. `IMPLEMENTATION_AND_EVIDENCE_CHECKLIST.md`: build, deploy, consumer and evidence checklist.
7. `AGENTS.md`: execution rules for Antigravity.
8. `.agents/rules/*`: persistent implementation rules.
9. `.agents/skills/*`: reusable implementation/evidence workflows.
10. `TASK_3_POST_DRAFT.md`: public post.

## Non-document deliverables
- database implementation
- repeatable seed script
- working API
- managed Postgres
- public deployment
- minimal consumer
- evidence screenshots

## Scope
Task 3 is primarily about the design and proof that the model holds. Do not expand it into a full marketplace application.
